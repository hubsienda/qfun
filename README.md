# QOOBIX

QOOBIX is a private market-intelligence application provisioned for selected business clients.

It is not a public SaaS, not a CRM, not a lead library, and not a dashboard monster.

The core promise is:

> Search a market. Detect opportunity. Download the intelligence.

QOOBIX creates structured market-intelligence outputs for commercial questions such as market entry, distributor discovery, partner discovery, competitor mapping, regional opportunity assessment, positioning, and action-priority work.

Generated outputs are delivered as downloadable DOCX and XLSX files.

---

## Core doctrine

QOOBIX stores the operational trail, not a permanent intelligence database.

The database stores:

1. Client configuration.
2. Hashed access codes and recovery phrases.
3. Job metadata.
4. Job status.
5. Report file metadata.
6. Operational logs.

Generated intelligence is packaged into files and stored temporarily.

The client must download and retain the generated files they need.

---

## Current operating model

QOOBIX is provisioned by the operator.

There is no public registration, no subscription checkout, and no Stripe flow at launch.

The operator creates a client environment through the hidden provisioning path. The client then uses their private access code to enter their client area, complete their business profile, create intelligence requests, and download generated outputs.

Payment is handled outside the application, for example by invoice and bank transfer.

---

## Main areas

### Public homepage

The homepage explains the service and offers:

1. Client access.
2. Service request by email.

No public page should reveal real client examples, private slugs, operational hints, or access naming conventions.

### Client access

Clients enter using their QOOBIX access code.

The access code is generated by QOOBIX/Proteus and is not chosen publicly by the client.

Clients may rotate their access code inside their client area after setting a recovery phrase.

### Client area

The client area allows the client to:

1. View and edit business profile.
2. Set or update recovery phrase/access code.
3. Create new intelligence requests.
4. View previous jobs.
5. Open ready results.
6. Download temporary DOCX/XLSX outputs.
